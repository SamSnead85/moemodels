# Support

MOEModels is experimental open-source software. There is currently no paid
support plan, uptime commitment, production-support SLA, or guaranteed response
time.

## Where to ask

- Use [GitHub Discussions](https://github.com/SamSnead85/moemodels/discussions)
  for usage questions, design discussion, and deployment-methodology questions.
- Use [GitHub Issues](https://github.com/SamSnead85/moemodels/issues) for a
  reproducible bug, source correction, or focused feature request.
- Use the structured issue forms for sourced model records and reproducible
  deployment cards.
- Follow [SECURITY.md](SECURITY.md) for suspected vulnerabilities. Do not put
  vulnerability details, credentials, private prompts, or customer data in a
  public issue or discussion.

Before opening a request, search existing issues and include the exact package
version, Node version, command, expected behavior, observed behavior, and a
minimal sanitized reproduction. For evidence questions, identify the exact
artifact, runtime, hardware topology, workload, and Passport or source locator.

Maintainers may redirect broad consulting, model-selection, procurement, or
production-operations requests to a narrower public question. A valid Passport
is not a support contract or production certification.
